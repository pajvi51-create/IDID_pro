# ระบบบริหารจัดการการเตรียมฝึกประสบการณ์วิชาชีพสำหรับนักศึกษาสาขาวิชาคอมพิวเตอร์
## Web Application for Professional Experience Preparation Management for Computer Students

โครงการพัฒนาเว็บแอปพลิเคชันสำหรับนักศึกษาสาขาวิชาคอมพิวเตอร์ มหาวิทยาลัยราชภัฏสกลนคร ด้วยสถาปัตยกรรม **Laravel 11 + Inertia.js (React 19) + Tailwind CSS + MySQL / SQLite** พร้อมระบบการตรวจพิจารณาอนุมัติแบบ **2 ลำดับขั้น (Two-Tier Approval Workflow)** อย่างสมบูรณ์

---

### 1. สถาปัตยกรรมและเทคโนโลยีที่ใช้ (Tech Stack)

* **Backend:** Laravel 11.56.1 (PHP 8.3)
* **Frontend:** Inertia.js + React 19 (Single Page Application UX without full-page reloads)
* **Styling & Design System:** Tailwind CSS v3.4 + ฟอนต์ภาษาไทย **LINE Seed Sans TH** (จัดเก็บแบบ Local Fonts โหลดเร็ว 100% ไม่พึ่งพา CDN ภายนอก)
* **Icons:** Lucide React
* **Database:** MySQL / SQLite พร้อม Foreign Key Constraints และ Normalized Schema
* **Security & Auth:** Laravel Session Authentication, Role-based Access Control (RBAC), Policy Authorization Gates, และ Form Requests Validation

---

### 2. บทบาทและสิทธิ์ผู้ใช้งาน (4 User Roles)

1. **นักศึกษาชั้นปีที่ 3 (`student`):**
   - ลงทะเบียน / เข้าสู่ระบบด้วยรหัสนักศึกษา (เช่น `67102122131`)
   - ศึกษาเกณฑ์และคุณสมบัติการเตรียมฝึกงาน
   - ค้นหาทำเนียบสถานประกอบการไอทีที่ทำ MOU และเปิดรับนักศึกษา
   - ดาวน์โหลดแบบฟอร์มเอกสารทางการ (คพ.01, คพ.02, หนังสือยินยอม)
   - ยื่นคำขออนุมัติสถานที่ฝึกงาน พร้อมแนบไฟล์เรซูเม่ (PDF), หนังสือตอบรับ และหนังสือยินยอม
   - ติดตามสถานะแบบเรียลไทม์ผ่าน **4-Step Visual Progress Stepper**

2. **อาจารย์ผู้รับผิดชอบรายวิชา (`instructor`):**
   - ตรวจสอบคุณสมบัตินักศึกษา ความเหมาะสมของสถานประกอบการ และเอกสารใน **ลำดับขั้นที่ 1**
   - ดำเนินการ: **อนุมัติส่งต่อขั้นที่ 2** หรือ **ส่งกลับเพื่อให้นักศึกษาแก้ไข** (พร้อมระบุคำแนะนำ) หรือ **ไม่อนุมัติ**

3. **ประธานหลักสูตร (`chair`):**
   - ตรวจสอบคำขอที่ผ่านการรับรองจากอาจารย์ผู้รับผิดชอบรายวิชาแล้วใน **ลำดับขั้นที่ 2 (ขั้นสุดท้าย)**
   - ดำเนินการ: **อนุมัติขั้นสุดท้าย** หรือ **ส่งกลับเพื่อแก้ไข**
   - บันทึกการอนุมัติเพื่อให้ออกหนังสือส่งตัวอย่างเป็นทางการ

4. **ผู้ดูแลระบบ (`admin`):**
   - ดูแลสิทธิ์ผู้ใช้, จัดการทำเนียบสถานประกอบการ (CRUD), จัดการแบบฟอร์มเอกสาร และปฏิทินกิจกรรม

### 3. โครงสร้างฐานข้อมูล (Database Schema)

| ตาราง | คำอธิบาย |
| :--- | :--- |
| `users` | บัญชีผู้ใช้งาน, รหัสนักศึกษา (`student_id`), เบอร์โทร, `role_id`, `curriculum_id` |
| `roles` | บทบาท 4 ระดับ: `student`, `instructor`, `chair`, `admin` |
| `curriculums` | หลักสูตรคอมพิวเตอร์ (เช่น วิทยาการคอมพิวเตอร์, เทคโนโลยีสารสนเทศ) |
| `companies` | ทำเนียบสถานประกอบการ, ลักษณะงาน, เบอร์ติดต่อ, จังหวัด, โควตาเปิดรับ, เบี้ยเลี้ยง |
| `applications` | คำขออนุมัติสถานที่ฝึกงาน, ตำแหน่งงาน, วันที่เริ่ม-สิ้นสุด, ข้อมูลผู้ประสานงาน, สถานะ |
| `application_documents` | ไฟล์เอกสารแนบ (Resume PDF, หนังสือตอบรับ, หนังสือยินยอม) พร้อมระบบจัดเก็บ |
| `approval_logs` | ประวัติการตรวจสอบแบบไม่ลบ (Audit Trail) บันทึกผู้ตรวจ, ขั้นตอน, ผล และหมายเหตุ |
| `timelines` | ปฏิทินกำหนดการสำคัญและวันหมดเขตยื่นเอกสาร (อิงปฏิทินจริงจาก com.snru.ac.th) |
| `guidelines` | คำแนะนำการทำ Resume, แนะนำ Portfolio (“Reboot ยังไง… ก่อนออกฝึก”) และเกณฑ์การลงทะเบียน |
| `downloadable_forms` | คลังแบบฟอร์มทางการเชื่อมโยงกับหน้าดาวน์โหลด com.snru.ac.th |

### 4. เอกสารทางการที่เชื่อมโยงจากเว็บไซต์ com.snru.ac.th

ระบบได้ดึงข้อมูลและแบบฟอร์มฉบับจริงจากหน้า **ดาวน์โหลด (https://com.snru.ac.th/ดาวน์โหลด)** มาไว้ในระบบ:
1. **แบบฟอร์มประวัตินักศึกษาฝึกประสบการณ์วิชาชีพคอมพิวเตอร์** (`.docx`): สำหรับส่งประวัติเมื่อผ่านการพิจารณา
2. **ขั้นตอนการเสนอและปฎิทินการฝึกประสบการณ์วิชาชีพคอมพิวเตอร์** (`.pdf`): หลักสูตรเทคโนโลยีคอมพิวเตอร์และดิจิทัล
3. **ขั้นตอนการเสนอที่ฝึกประสบการณ์วิชาชีพคอมพิวเตอร์** (`.pdf`): แผนผังขั้นตอนการปฏิบัติของสาขาวิชาคอมพิวเตอร์
4. **แบบฟอร์มเค้าโครงโครงงาน (คง.ค 1)** (`.pdf`): แบบฟอร์มเสนอเค้าโครงโครงงานด้านคอมพิวเตอร์
5. **แบบขอเสนอสอบหัวข้อโครงงานคอมพิวเตอร์ 1 (คง.ค. 2)** (`.pdf`): แบบคำขอเสนอสอบหัวข้อ
6. **แบบคำขอทั่วไป สาขาวิชาคอมพิวเตอร์ (คง.ค.-6)** (`.docx`): แบบฟอร์มคำร้องทั่วไป
7. **คู่มือโครงงานคอมพิวเตอร์และการเตรียมตัวฝึกงาน ฉบับสมบูรณ์** (`.pdf`): คู่มือการจัดทำรูปเล่มและแนวทางการฝึกงาน
8. **ปุ่มลิงก์ตรงไปยังหน้าเว็บไซต์ทางการ:** [https://com.snru.ac.th/ดาวน์โหลด/](https://com.snru.ac.th/%e0%b8%94%e0%b8%b2%e0%b8%a7%e0%b8%99%e0%b9%8c%e0%b9%82%e0%b8%ab%e0%b8%a5%e0%b8%94/)

### 5. ระบบสมุดบันทึกการปฏิบัติงานประจำวันและการนิเทศก์งาน (Daily Logbook & Supervision)

ระบบรองรับการบันทึกและติดตามผลการฝึกงานแบบครบวงจร:
* **มุมมองนักศึกษา (Student View):**
  - บันทึกการปฏิบัติงานประจำวัน: วันที่, เวลาเข้า-ออก, จำนวนชั่วโมง, หัวข้องาน, รายละเอียดงาน, ทักษะ/เทคโนโลยีที่ใช้ (Tech Stack tags เช่น Laravel, React, Docker, Git), ปัญหาที่พบ, วิธีการแก้ไข, และสิ่งที่ได้เรียนรู้ (Learning Outcome)
  - ประวัติการบันทึกย้อนหลัง (Day-by-Day Timeline) พร้อมตัวกรองสถานะ และติดตามชั่วโมงสะสมเทียบกับเกณฑ์ 400 ชั่วโมง
  - กล่องแสดงข้อเสนอแนะและคำแนะนำทางวิชาการจากอาจารย์นิเทศก์เมื่อได้รับการตรวจรับรอง
* **มุมมองอาจารย์นิเทศก์และประธานหลักสูตร (Instructor & Chair Supervision View):**
  - เลือกลิสต์นักศึกษา (Student Roster Selector) เพื่อเจาะจงตรวจดูบันทึกของนักศึกษาแต่ละคนได้โดยตรง
  - ตรวจสอบประวัติการบันทึกงานรายวันของนักศึกษาที่เลือกแบบละเอียด
  - ระบบตรวจรับรอง (Sign-off & Verify) พร้อมบันทึกความคิดเห็น/คำแนะนำทางวิชาการและการปฏิบัติงาน

### 7. คำสั่งสำหรับรันระบบ (How to Run)

```bash
# 1. ติดตั้ง Dependencies
composer install
npm install

# 2. จำลองฐานข้อมูลและ Seeding
php artisan migrate --seed

# 3. รันเซิร์ฟเวอร์ Backend (Laravel)
php artisan serve --port=8000

# 4. รันเซิร์ฟเวอร์ Frontend (Vite)
npm run dev

# 5. หรือคอมไพล์โปรดักชัน
npm run build
```
เปิดใช้งานผ่านเว็บเบราว์เซอร์ที่: **`http://127.0.0.1:8000`**
